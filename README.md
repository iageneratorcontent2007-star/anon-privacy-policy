# Anon — Privacy Policy

Public Privacy Policy page for the Anon app.

After GitHub Pages is enabled, the live URL is:

`https://YOUR_GITHUB_USERNAME.github.io/anon-privacy-policy/`

Replace `YOUR_GITHUB_USERNAME` with your GitHub username. Use that URL in Google Play Console.

## Files

- `index.html` — the Privacy Policy page
- `delete-account.html` — account deletion instructions for Google Play
- `.nojekyll` — tells GitHub Pages not to process the site with Jekyll

## Publish

1. Create a public GitHub repository named `anon-privacy-policy`.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the `main` branch.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select **main** and **/ (root)**.
6. Wait for the green Pages URL.
7. Open the URL in an incognito window and confirm the policy loads over HTTPS.
8. Paste the same URL into Google Play Console.

Do not commit `.env` files, API keys, or service-role keys.
